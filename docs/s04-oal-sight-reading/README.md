# Session 4 OAL: sight-reading files

The routes you read in the Session 4 OAL ("Four Doors, One Route"), as plain files.

**They are for reading, not running.** Nothing in `app.js` loads them, and each one leaves out the connection code so the data flow is easy to see. Write your answers down before you check them in the OAL.

| File | OAL part |
|---|---|
| `exercise-1-two-doors.js` | Exercise One: where does each value come from? |
| `exercise-2-form.js` and `exercise-2-json.js` | Exercise Two: two ways into `POST /members` |
| `cold-read-three-doors.js` | The cold-read: what do `req.params`, `req.query` and `req.body` hold? |
